🧾 Resume Builder

A web-based Resume Builder that allows anyone to easily create and customize their own professional resume.
Built using HTML, CSS, and JavaScript, this project helps users input their details and instantly generate a clean, formatted resume — all within their browser.

🚀 Features

🧍‍♂️ Form-based input for personal, education, and skills details

⚡ Real-time preview of resume layout

📝 Auto-generated, styled resume output

💾 Option to download or print resume

🌐 Fully responsive and lightweight web app

🚀 Hosted using GitHub Pages

🧰 Tech Stack

HTML5 – Structure and form elements

CSS3 – Styling and responsive design

JavaScript – Dynamic form handling and resume generation

Git & GitHub – Version control and deployment

🖥️ Live Demo

👉 Try the Resume Builder - https://tanishj2006.github.io/web-resume/

⚙️ How to Use

Open the website (live demo link above).

Fill in your details like name, skills, education, and projects.

Click Generate Resume to view your formatted resume instantly.

Print or save the resume as a PDF.
